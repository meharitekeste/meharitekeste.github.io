# Soil Machine Dynamics Laboratory (SMDL) website

Website of the Soil Machine Dynamics Laboratory, Department of Agricultural and Biosystems Engineering, Iowa State University (Director: Dr. Mehari Tekeste).

Live site: https://meharitekeste.github.io/

## How it works
- Plain HTML and CSS, no framework or build step. Each page is one `.html` file; all styling is in `styles.css`.
- Photos are in `img/`, background videos (silent) are in `media/`.
- GitHub Pages publishes the `main` branch automatically. Any change committed to `main` is live in about a minute.

## Editing
- Small text changes: open the page on github.com, click the pencil icon, edit, and "Commit changes".
- Larger changes: clone with GitHub Desktop, edit in VS Code, commit, then "Push origin".
